# Product

## Register

product

## Users

HuuQuantAI is for a solo operator building and validating crypto quantitative trading workflows on a local Windows workstation. The user needs to inspect Binance public market data, run strategy checks, review risk controls, place simulated orders, and understand system state without exposing real trading paths by default.

## Product Purpose

HuuQuantAI is a local cryptocurrency quant trading workbench. It combines Binance public quotes, local paper trading, strategy validation, backtesting, audit trails, AI-assisted explanations, and desktop packaging into one controlled environment. Success means the operator can trust the local system state, test ideas safely, and clearly see that real trading remains off unless a future explicit confirmation flow enables it.

## Brand Personality

Precise, calm, and protective. The interface should feel like a disciplined trading terminal: dense enough for serious work, restrained enough to reduce mistakes, and clear enough that safety boundaries are never hidden.

## Anti-references

Avoid consumer crypto casino styling, neon overload, decorative fintech dashboards, vague AI assistant branding, legacy desktop-app naming, and any UI pattern that makes simulated trading look like live exchange execution.

## Design Principles

- Make safety visible before action.
- Prefer working controls and current state over marketing copy.
- Keep crypto-only language consistent across startup, login, trading, risk, and audit surfaces.
- Use restrained terminal-like contrast, clean hierarchy, and familiar product UI controls.
- Never imply that AI or automation can bypass local risk and manual confirmation boundaries.

## Accessibility & Inclusion

Target readable contrast for long desktop sessions, keyboard-friendly form controls, clear focus states, and reduced-motion-safe status feedback. Chinese UI text should be encoded as UTF-8 and remain legible in packaged desktop builds.
